# Support

- Use [GitHub Discussions](https://github.com/ddtdanilo/ut383bt-lux-ble-python/discussions)
  for setup questions and compatible-device observations.
- Use [GitHub Issues](https://github.com/ddtdanilo/ut383bt-lux-ble-python/issues)
  for reproducible defects and feature proposals.
- Use private vulnerability reporting for security or privacy concerns.

Include the project version, Python version, Bleak version, operating system,
command, sanitized error, and whether the meter appears in `ut383bt scan`.

Remove device identifiers, unrelated scan results, personal data, and sensitive
measurement logs before posting.
